Reckon

A calculator in the spirit of SpeedCrunch: expressions into a history, variables and your own functions, graphs of y = f(x), and JavaScript against the calculator.

Download Nightly Source on GitHub

What it does

  • Type expressions, get results in a live history: every result has a name like $3, and editing an entry in place updates everything that depends on it, like QML bindings.
  • Variables, f(x) = … functions, ans, and sessions that come back when Reckon starts.
  • Results as general, fixed, scientific, engineering, binary, octal or hexadecimal numbers, at the precision you pick.
  • Colors in the expression, the result while you type, and completion of function and variable names.
  • Graphs of y = f(x) curves that follow the calculator’s variables: pan, zoom, read values off the plot.
  • JavaScript scripts that evaluate expressions, define functions the calculator can call, and plot, with each run’s curves and output side by side.

Debian and Ubuntu

The APT repository brings Reckon with its own Qt.

sudo curl -fsSLo /usr/share/keyrings/reckon-archive-keyring.asc https://iam-peter.github.io/reckon/key.asc
echo "deb [signed-by=/usr/share/keyrings/reckon-archive-keyring.asc] https://iam-peter.github.io/reckon/apt stable main" | sudo tee /etc/apt/sources.list.d/reckon.list
sudo apt update && sudo apt install reckon

Other systems

Each release has an AppImage for any Linux, a zip for Windows and a disk image for macOS. The macOS app isn't signed: open it with a right click and Open the first time.
